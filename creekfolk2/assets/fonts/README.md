# Fonts

Embedded in the page at build time (`tools/build.mjs`), so the game never loads anything
from the network. Latin subsets, as served by Google Fonts on 2026-10-21. All three are
under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows embedding
and redistribution.

- `Gloock-normal-400.woff2`: Gloock, by Duarte Pinto (headings).
- `HankenGrotesk-normal-400-600.woff2`, `HankenGrotesk-italic-400.woff2`: Hanken Grotesk, by
  Alfredo Marco Pradil and Hanken Design Co. (text; the upright one is variable, 400 to 600).
- `IBMPlexMono-normal-400.woff2`, `IBMPlexMono-normal-500.woff2`: IBM Plex Mono, by Mike Abbink
  and Bold Monday for IBM (small labels and numbers).

These are the fonts What the Water Brings uses.
